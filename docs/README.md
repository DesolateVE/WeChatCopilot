# 文档导航

文档按读者分为两套，避免把长篇研究记录默认塞入 AI 上下文。

- [开发者文档](developer/README.md)：架构、数据库关系、逆向证据、构建和操作流程。
- [AI 上下文](ai/README.md)：任务路由、硬约束、当前结论和可检索 schema。
- [参考资料](reference/)：保留原始格式的人工参考文档。

新增文档时，面向人类解释“为什么、如何验证、如何操作”的内容放 `developer/`；
只为 AI 恢复任务状态提供的短结论、约束和索引放 `ai/`。真实聊天记录、数据库和密钥
一律放 `local-data/`，不得进入任一文档目录。
